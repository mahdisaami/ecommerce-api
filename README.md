# E-commerce API

A production-oriented E-commerce REST API built with Django and Django REST Framework.

## Tech Stack

- Python

- Django

- Django REST Framework

- PostgreSQL

- JWT Authentication

- Docker

## Current Features

- Custom User Model

- JWT Authentication

- User Registration

- User Login

- User Logout (Refresh Token Blacklisting)

## Upcoming Features

- Product Management

- Shopping Cart

- Order Management

- Seller & Admin Roles

- Redis

- Celery

- Email Notifications

- Dockerized Django

- API Documentation
